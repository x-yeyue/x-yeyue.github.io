定理 ​

算数基本定理(唯一分解定理) ​

算数基本定理(fundamental theorem of arithmeticfundamental ~ theorem ~ of ~ arithmeticfundamental theorem of arithmetic, 又称唯一分解定理，unique factorization theoremunique ~ factorization ~ theoremunique factorization theorem) —— 任意合数 ccc 可以表示成有限个素数 pip_{i}pi​ 的乘积，而且在不考虑素数乘积顺序的情况下其表示方式唯一。

c=p1e1p2e2⋯pnenc = p_{1}^{e_{1}} p_{2}^{e_{2}} \cdots p_{n}^{e_{n}} c=p1e1​​p2e2​​⋯pnen​​

引理： 对任意大于 111 的正整数 nnn ，nnn 至多有一个大于 n\sqrt{n}n​ 的质数。假设该质数存在，它的唯一分解式子中的质数一定为 111 。

ap−1≡1(modp)a^{p-1} \equiv 1 \pmod{p} ap−1≡1(modp)

裴蜀定理 ​

如果 aaa 和 bbb 是不全为 000 的整数，则有整数 xxx、yyy，使得 ax+by=gcd⁡(a,b)ax + by = \gcd\left(a, b\right)ax+by=gcd(a,b)。

推论：

  1. 如果 aaa 和 bbb 是不全为 000 的整数，且 aaa 和 bbb 互质，当且仅当存在整数 xxx、yyy，使得 ax+by=1ax+by=1ax+by=1 。
    • 若 ax+by=1ax+by=1ax+by=1，则 aaa 和 bbb 互质。
  2. 如果 aaa 和 bbb 是不全为 000 的整数，并且 ax+by=cax + by = cax+by=c 有整数解解，那么 ccc 一定是 gcd⁡(a,b)\gcd\left(a,b\right)gcd(a,b) 的整数倍。
    • 若 ccc 不是 gcd⁡(a,b)\gcd\left(a,b\right)gcd(a,b) 的整数倍，那么 ax+by=cax + by = cax+by=c 就没有整数解。
  3. aaa 和 bbb 两项的裴蜀定理，可以推广到多项的情况。
    • 例如: ax+by+cz+dp=gcd⁡(a,b,c,d)=sax + by + cz + dp=\gcd\left(a,b,c,d\right) = sax+by+cz+dp=gcd(a,b,c,d)=s

注：如果 ax+by=cax + by = cax+by=c一旦有解，就意味着一定有无穷多组 (x,y)\left(x, y\right)(x,y)，都可以使得式子成立。

整除性 ​

如果 aaa 和 bbb 为整数且 a≠0a \neq 0a=0，aaa 整除(dividesdividesdivides) bbb 是指存在整数 ccc 使得 b=acb = acb=ac，如果 aaa 整除 bbb，称 aaa 是 bbb 的一个因子，且称 bbb 是 aaa 的倍数，将其记为 a∣ba \mid ba∣b，如果 aaa 不能整除 bbb，则将其记为 a∤ba \nmid ba∤b。

素数 ​

对于整数 a>1a \gt 1a>1，如果它只能被 111 和自身整除，则称 aaa 为素数（prime numberprime ~ numberprime number，或称质数）。 对于大于 111 的整数 aaa 来说，如果 aaa 不是素数，则称 aaa 为合数（composite numbercomposite ~ numbercomposite number）。
合数可以表示成素数的乘积，如果不考虑乘积的顺序，其表示方式是唯一的，此即算数基本定理。

素数判定 ​

可以通过筛法将所有的素数都筛选出来，后直接判断。也可以朴素的判断。

朴素判断

c++
bool isPrime(int a){
    if(a <= 1) return false;
    if(a == 2) return true;
    if(!(a & 1)) return false;
    int fac = (int)sqrt(a);
    for(int i = 3; i <= fac; i += 2){
        if(a % i == 0) return false;
    }
    return true;
}

筛法 ​

判断一个区间内有哪些质数。

朴素筛 ​

c++
bool judge[maxn]; // 是否是非质数 true:非质数
int prime[maxn], cnt = 0; // 存储发现的质数,质数的数量
int getPrimes(int n){
    for(int i = 2; i <= n; i ++){
        if(!judge[i]){
            prime[cnt ++] = i;
        }
        for(int j = i * i; j <= n; j += i){ // 将其的倍数标记非质数
            judge[j] = true;
        }
    }
    return cnt;
}

素因子分解 ​

根据算数基本定理，任意合数都可以表示为素数的乘积形式，即给定合数 ccc，可以将其表示为以下形式。

unordered_map<int, int> get_prime_fac(int x){
    unordered_map<int, int> fac;
    if(x == 0){
        return fac;
    }
    fac[1] = 1;
    for(int i = 2; i * i <= x; i ++){
        if(x % i != 0) continue;
        while(x % i == 0){
            fac[i] ++;
            x /= i;
        }
    }
    if(x > 1) fac[x] ++;
    return fac;
}

互质 ​

如果正数 aaa 和 bbb 的最大公因数为 111，则称 aaa 和 bbb 互素(relative primerelative ~ primerelative prime，或称互质)。

  • 显然两个素数的最大公约数为 111，有时两个非质数的最大公约数也可能为 111，如 444 和 999。
  • 大于 111 的两个质数总是互质的。

互质的性质 设 a<ba \lt ba<b，则 ka(1≤k≤b)ka\left(1 \leq k \leq b\right)ka(1≤k≤b) 除以 bbb 的余数会取遍 0∼b−10 \sim b-10∼b−1 且不会发生重复。 例如： 555 和 777 互为质数，则 5k(1≤k≤7)5k(1 \leq k \leq 7)5k(1≤k≤7) 除以 777 的余数依次为 555、333、111、666、444、222、000，取遍了 0∼60 \sim 60∼6 的余数值。

循环分解 ​

定义 ​

排列的循环分解是将一个排列(1∼N1 \sim N1∼N 的不重复序列)拆解为若干个不相交的循环的过程。每个元素属于且仅属于一个循环，循环内的元素沿着“位置->该位置的值->该值对应的位置”的路径最终回到起点，形成闭环。

  • 排列: 长度为 NNN 的序列 P=(P1,P2,⋯ ,PN)P = (P_1, P_2, \cdots, P_N)P=(P1​,P2​,⋯,PN​)，其中每个数是 1∼N1 \sim N1∼N 的唯一值。
  • 循环: 对排列中的元素 xxx，沿着路径 x→P[x]→P[P[x]]→⋯→xx \to P\left[x\right] \to P\left[P[x]\right] \to \cdots \to xx→P[x]→P[P[x]]→⋯→x 的遍历，最终回到起点，这条路径就是一个循环(也叫轮换)。

单循环: 例如 N=3,P=[2,3,1]N = 3, P = \left[2, 3, 1\right]N=3,P=[2,3,1] 可以分解为一个循环 (1, 2, 3)。 双循环: 例如 N=4,P=[2,1,4,3]N = 4, P = \left[2, 1, 4, 3\right]N=4,P=[2,1,4,3] 可以分解为两个循环 (1, 2) (3, 4)。 含自环: 例如 N=3,P=[1,3,2]N = 3, P = \left[1, 3, 2\right]N=3,P=[1,3,2] 可以分解为两个循环 (1) (2, 3)。

性质 ​

  1. 不相交性: 任意两个循环没有公共元素(每个元素属于且仅属于一个循环)。
  2. 覆盖性: 所有循环的元素集合恰好是排列的全部元素(1∼N1 \sim N1∼N)。
  3. **循环的长度和 = 排列长度 NNN 设循环分解为 C1,C2,⋯ ,CmC_{1}, C_{2}, \cdots, C_{m}C1​,C2​,⋯,Cm​，每个循环 CiC_{i}Ci​ 的长度为 LiL_{i}Li​，则 ∑i=1mLi=N\sum_{i = 1}^{m} L_{i}= N∑i=1m​Li​=N。
  4. 循环分解的唯一性(不考虑顺序和起始点)
  5. 最小交换次数 = N −= ~ N ~ -= N − 循环个数 mmm。 排列还原为升序(1,2,3,⋯ ,N1,2,3,\cdots,N1,2,3,⋯,N)的最小交换次数，等于 “元素总数 NNN” 减去 “循环的个数 mmm”。
    • 原理: 长度为 LLL 的循环，需要 L−1L - 1L−1 次交换才能将其所有的元素归位。

极角排序 ​

数学定义与几何意义 ​

对于二维平面上的两个向量 a⃗=(x1,y1)\vec{a} = (x_1, y_1)a=(x1​,y1​) 和 b⃗=(x2,y2)\vec{b} = (x_2, y_2)b=(x2​,y2​)，它们的叉积被定义为一个标量（即一个实数）：

a⃗×b⃗=x1⋅y2−y1⋅x2\vec{a} \times \vec{b} = x_1 \cdot y_2 - y_1 \cdot x_2 a×b=x1​⋅y2​−y1​⋅x2​

几何意义：这个标量的绝对值等于以 a⃗\vec{a}a 和 b⃗\vec{b}b 为邻边构成的平行四边形的有向面积。

符号与方向判断 ​

叉积的符号直接告诉我们 b⃗\vec{b}b 相对于 a⃗\vec{a}a 的旋转方向。

假设你站在原点，面朝向量 a⃗\vec{a}a 的方向：

  • 若 a⃗×b⃗>0\vec{a} \times \vec{b} > 0a×b>0（叉积为正）：b⃗\vec{b}b 在你的左手边（逆时针方向）。
  • 若 a⃗×b⃗<0\vec{a} \times \vec{b} < 0a×b<0（叉积为负）：b⃗\vec{b}b 在你的右手边（顺时针方向）。
  • 若 a⃗×b⃗=0\vec{a} \times \vec{b} = 0a×b=0：两个向量共线（在同一条直线上），可能同向也可能反向。

template <typename T>
struct point{
    T x, y;
    point() : x(0), y(0){}
    point(T _x, T _y) : x(_x), y(_y){}
    // 叉乘
    T cross(const point<T> &b)const{
        return x * b.y - y * b.x;
    }
    T cross(const point<T> &a, const point<T> &b){
        return a.x * b.y - a.y * b.x;                                               
    }
    // 逆时针
    bool operator<(const point<T> &nxt)const{
        // 是否在 x 轴上方
        bool a = y > 0 || y == 0 && x > 0;
        bool b = nxt.y > 0 || nxt.y == 0 && nxt.x > 0;
        if(a ^ b) return a; // 不同区域
        return cross(nxt) > 0;
    }
    // 到达 点o 的距离的平方

    }

c++
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

struct Point {
    ll x, y;
    int quad() const {   // 获取象限（逆时针顺序：1→2→3→4）
        if (x > 0 && y >= 0) return 1;
        if (x <= 0 && y > 0) return 2;
        if (x < 0 && y <= 0) return 3;
        if (x >= 0 && y < 0) return 4;
        return 0; // 原点
    }
    ll cross(const Point& b) const { return x * b.y - y * b.x; }
};

// 逆时针极角排序比较器
bool cmp_polar(const Point& a, const Point& b) {
    if (a.quad() != b.quad()) return a.quad() < b.quad();
    ll c = a.cross(b);
    if (c != 0) return c > 0;          // b 在 a 的逆时针方向
    return a.x * a.x + a.y * a.y < b.x * b.x + b.y * b.y; // 共线按距离
}

// 使用示例
vector<Point> pts = { {1,1}, {-1,2}, {-2,-1}, {2,-1} };
sort(pts.begin(), pts.end(), cmp_polar);

多边形求面积 ​

c++
struct Point {
    ll x, y;
};

// 鞋带公式求多边形面积，返回面积的两倍（避免浮点运算），实际面积需除以2.0
ll area2(const vector<Point>& poly) {
    int n = poly.size();
    if (n < 3) return 0; // 不是多边形
    ll sum = 0;
    for (int i = 0; i < n; ++i) {
        int j = (i + 1) % n;
        sum += poly[i].x * poly[j].y - poly[j].x * poly[i].y;
    }
    return abs(sum);
}

// 若需返回浮点数面积
double area(const vector<Point>& poly) {
    return area2(poly) / 2.0;
}
